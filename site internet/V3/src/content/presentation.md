# JEGEEKUTILE

**JeGeekUtile** est une association tech qui transforme la passion informatique en compétences concrètes. On crée des projets réels, on code ensemble, et on s'éclate en apprenant.

Pas de cours magistraux. Pas de théorie barbante. Juste **du code, des projets, et une communauté de geeks motivés**.


## Pourquoi nous rejoindre ?

### # PROJETS TECH RÉELS
Tu travailles sur de **vrais projets** :
* **Développement** (Python, Flask, HTML/CSS/JS)
* **Applications modulaires** (architecture plugin, scalable)
* **Gestion de données** (bases de données, API)
* **DevOps** (Docker, CI/CD, déploiement)
* **UI/UX** (création d'interfaces utilisateur)
* **Jeux vidéos** (en 2D avec pygame pour le moment)

### # VALORISE TON PROFIL
* **Projets à mettre sur ton CV** (code open source, contributions réelles)
* **Portfolio tech** concret (GitHub, démos en ligne)
* **Expérience collaborative** (Git, revues de code, méthodologies agiles)

### # À TON RYTHME
* **Pas d'obligation** : tu contribues quand tu veux
* **Choisis tes projets** : installe les apps qui t'intéressent
* **Progression visible** : tu vois ton évolution en temps réel
* **Feedback constructif** : code reviews bienveillantes
