Le concept

Un rendez-vous. Chaque semaine. Pour ne pas subir l'IA, mais la piloter.

Le vibe coding change la manière de produire du logiciel : on décrit une intention, l'IA génère le code. Mais générer ne suffit pas. Celui qui ne sait que demander reste dépendant. Celui qui sait aussi lire, débugger et corriger garde le contrôle. Ces sessions hebdomadaires existent pour développer les deux réflexes, en pratiquant sur de vrais projets, entre étudiants en informatique.

L'équation

Deux compétences, une seule personne.

Demain, la rareté ne sera plus de savoir coder ligne par ligne, ni seulement de savoir prompter une IA. La vraie valeur, c'est de réunir les deux.

Vibecoder sans comprendre = dépendance. Comprendre sans vibecoder = lenteur. Les deux réunis = le profil que le marché s'arrachera.

Algorithmique, architecture, structures de données, débogage, lecture de code : tout ce que tu apprends est précisément ce qui manque à ceux qui ne savent que prompter. Ces sessions ne remplacent pas ta formation — elles la branchent sur les outils d'aujourd'hui pour te transformer en développeur double compétence.

L'arsenal

Les outils qu'on va maîtriser.

Pas de théorie abstraite — on apprend sur les vrais outils du vibe coding professionnel, ceux que les meilleurs développeurs utilisent aujourd'hui.

[ 01 ] GITHUB
GitHub

Versionner, collaborer, et piloter des projets entiers avec Copilot intégré directement dans les PR.

[ 02 ] VSCODE
VSCode

L'éditeur central du workflow IA. Extensions, terminal intégré, debug et agents dans un seul espace.

[ 03 ] CLAUDE CODE
Claude Code

L'agent IA en ligne de commande d'Anthropic. Il lit, écrit et modifie ta codebase en dialogue direct.

[ 04 ] CODEX
Codex

L'agent cloud d'OpenAI qui exécute des tâches de développement en autonomie depuis un repo GitHub.

[ 05 ] ANTIGRAVITY
Antigravity

Outil de vibecoding nouvelle génération pour construire des interfaces et des apps à partir de descriptions.

[ 06 ] ZCODE
Zcode

Environnement de développement assisté par IA pour accélérer les cycles de code, test et déploiement.

Niveau supérieur

Orchestrer plusieurs agents, pas juste prompter un chatbot.

Le vibecoding sérieux ne se résume pas à une conversation avec une IA. C'est savoir configurer un projet pour le piloter avec plusieurs agents, maîtriser le contexte qu'on leur donne et minimiser les tokens. C'est ce qui sépare l'amateur du développeur réellement augmenté.

> MULTI-AGENTS
Configurer un projet multi-agents

Préparer une codebase pour la vibecoder avec plusieurs agents de codage différents (Claude Code, Codex, agents locaux) sans qu'ils se marchent dessus.

> CONTEXTE & TOKENS
Process de gestion du contexte

Créer des process optimisés pour donner le bon contexte au bon moment, minimiser les tokens consommés et gérer proprement le passage entre différentes conversations.

> AGENTS PARALLÈLES
Plusieurs agents, plusieurs tâches

Créer et coordonner plusieurs agents qui travaillent en parallèle sur des tâches différentes d'un même projet, puis assembler leurs résultats.
